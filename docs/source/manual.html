Gesture Calculator

User Manual: how to use it and how it works

A scientific calculator operated with hand gestures in front of a webcam

Windows · runs entirely offline

1 Overview

Gesture Calculator is a scientific calculator with no keys to press. The left hand shows the digits. The right hand, held on a whiteboard in the camera picture, shows two digits that together select an operator or a function.

[[IMG:overview.png]]

Figure 1 The idea in one picture

HandWhat it showsWhat is entered
Left handone gesture, held still for 1 seconda digit, ., =, DEL or AC
Right hand, on the whiteboardtwo digit gestures, 0.5 second each, tens firstthe operator with that two-digit code

The program never uses the internet. Camera pictures are processed on this computer and are not stored.

2 Getting started

2.1 What you need

ItemRequirement
ComputerWindows 10 or 11, 64-bit
Cameraany webcam (the built-in one of a laptop is fine)
FilesGestureCalculator.exe, the folder _internal and the folder models, kept together
Installationnone: no Python, no internet connection

2.2 Start

  1. Double-click GestureCalculator.exe.
  2. Wait a few seconds until the camera picture appears.
  3. Sit 40–80 cm from the camera, in good light, with both hands able to reach into the picture.

3 Left hand: digits and editing

The left hand enters the digits, the decimal point, =, DEL and AC. Hold a gesture still for 1 second. A green ring fills around the hand; when it is full, the key is entered.

[[IMG:gestures.png]]

Figure 3 The fourteen gestures of the left hand

To do thisDo this
Enter the next characterchange to the next gesture and hold it
Enter the same character twice (55)after the first one, move the hand aside and back, then hold the gesture again
Delete the last characterthumb down (DEL)
Clear everythingcross both forearms, away from the whiteboard (AC)
Work out the resultthumb up (=)

A held gesture is entered only once. A hand shape shown only in passing, on the way to the next gesture, is ignored.

4 Right hand: operators

4.1 Entering a code

The whiteboard is the light panel in the top right of the camera picture. Put the right hand on it and show two digits, each for 0.5 second: first the tens digit, then the units digit. The digit gestures are the same as for the left hand; an orange ring shows the time running.

[[IMG:whiteboard.png]]

Figure 4 Code 10 enters sin

  • The right hand counts only while its palm is on the whiteboard, and it can only enter code digits.
  • A code that does not exist enters nothing.
To correct thisDo this
A wrong tens digittake the hand off the whiteboard; after 6 seconds the digit is dropped
A wrong operatordelete it with the left hand (thumb down, DEL)

8 How it works

8.1 From the camera picture to a key

[[IMG:pipeline.png]]

Figure 7 What happens to every camera frame

StepWhat it does
Hand trackingMediaPipe finds up to two hands, 21 points on each, and tells the left hand from the right. The picture is mirrored, so the right hand appears on the right.
StillnessA hand is still while its palm and index fingertip stay inside a small circle. This tolerates the slight tremor of a raised hand.
One hand per lookThe gesture network judges the whole picture and names one gesture. So each hand gets its own look, with the other hand painted over in grey.
Gesture networkResNet-152, a deep convolutional network pre-trained on the HaGRID gesture data set, gives a probability to each of 34 gestures.
AveragingThe answers for all frames of the pause are averaged, so one bad frame does not decide.
CalculatorThe key is added to the expression; = works it out.

8.2 When a gesture is entered

[[IMG:decision.png]]

Figure 8 The decision for each hand

"Network sure" means: the calculator's gestures together receive at least 30% of the probability, and the best one at least half of that. Otherwise nothing is entered and the window shows the closest guess.

8.3 The models

File in the models folderRole
hand_landmarker.taskMediaPipe hand tracker: where the hands are and which one is the left
gesture_resnet152.onnxResNet-152 gesture network (used by default)
gesture_vit_b16.onnxViT-B/16, a vision transformer trained on the same data; an optional alternative

Both gesture networks are the published HaGRID models, converted to the ONNX format. Nothing is trained on this computer. They run on the processor with ONNX Runtime; no graphics card is needed.

9.1 Running from the source code

The source code does not contain the gesture network (it is too large). Step 2 creates it once: the script downloads the published HaGRID model and converts it. This step needs the internet; running the calculator does not.

# 1. environment
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

# 2. the gesture network, once
.venv\Scripts\python -m pip install -r tools\requirements-convert.txt
.venv\Scripts\python tools\convert_hagrid.py --arch resnet152

# 3. start
.venv\Scripts\python app\main.py
OptionEffect
--camera 1use another webcam
--no-camerakeyboard only
--gesture-model vit_b16use the ViT-B/16 network instead of ResNet-152 (convert it first with --arch vit_b16)

9.2 Building the exe

.venv\Scripts\python -m pip install pyinstaller
pwsh build_exe.ps1

The script writes GestureCalculator.exe and _internal into the project folder.

10 Troubleshooting

ProblemWhat to do
"No webcam found"connect a camera, close other programs that use it, start again; or start with --camera 1
"gesture model missing"put gesture_resnet152.onnx and gesture_resnet152.json into models
No outline on a handbring the whole hand into the picture; improve the light
The ring never fillshold the hand still; rest the elbow on the table
"Gesture not recognised"face the palm to the camera, spread the fingers clearly, keep the other hand away from it
A digit is entered twicekeep the hand still after an entry until you change the gesture
The right hand enters nothingits palm must be on the whiteboard
The hands are taken for each otherkeep them apart; if it is always wrong, tick Swap hands
"There is no operator with the code …"check the code list; enter the tens digit first
